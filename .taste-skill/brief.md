# Mystack workshop: preserve the style, repair the mechanism

The user approves the dark background, warm line art and typography. Preserve those choices. Fix perspective deformation and perceived stutter, make the machines recognizable and their actions logically related to the page, and vary their side and position across routes. The site remains English-only, built in TanStack Start, with real integration choices and no Play/Pause controls.

The visual world is one printer's workshop. The configurable object is an open platen letterpress: runtime = drive, database = type chase, email = paper delivery, optional payments = extra marking heads. A composing stick explains configuration, a type cabinet explains code ownership, and a cutaway padlock explains verification before access. Descriptions name each object and explain the analogy. The press's paper, crank, connecting rod and platen share one physical sequence.

Keep the Blender source. Export real rigid GLB batches and outline geometry; use Three.js with depth testing for animation. SVG is a still poster, never an affine approximation of a rotating solid. Use unit-scale rigid transformations, time-based following and one scheduled frame loop. Cache resources across routes, stop idle/hidden work, cap pixel density and preserve a static SSR/reduced-motion experience.

Compose art left on Configuration, Foundation, Project structure, Documentation and Quick start. Compose it right on Home, Integrations, Authentication and Deployment. Add restrained movement through a real camera and viewport displacement. Keep text readable with the established ground-tone backing. Motion completes during the reading area, before the footer covers it.

The lock must read as a physical object: the key teeth align beneath the five pins at full insertion; the bow is in the blade's plane; and the longer shackle leg remains captured when the short leg releases. Verify these constraints on the exported model, not just the phase names.
